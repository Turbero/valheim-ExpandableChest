# Expandable Chests

< Commissioned > This mod helps you expand main vanilla containers in the game at the cost of the original materials to add extra rows.

![](https://i.imgur.com/QtiTRXH.gif)

# How it works

Vanilla containers will have two extra buttons:
* Add Row: expand one extra row at the cost of some materials
* Reset: takes the container back to its original size (current content is dropped to the ground)

Containers available for expansion:
* Wood chest
* Reinforced chest (iron)
* Black metal chest
* Grausten Chest (Ashlands)
* Timberwood Wardrobe (Deep North)

Configure the options at your choice (all is server-synced):
* Allow to expand or reset at your choice.
* Amount of resources needed to expand a container (default = half the original cost)
* Number of expansions allowed (default = 2) 
* Text Translations
